## Featured projects

### [LocalSecureVault](https://github.com/carlos-aisa/LocalSecureVault)

Local-first encrypted vault for credentials and personal secrets, built with .NET MAUI Blazor.

* AES-GCM authenticated encryption and Argon2id key derivation
* Windows desktop application and Android companion
* Security-focused tests and tamper detection
* Automated builds, CodeQL analysis and release artifacts
* No cloud dependency: users retain control of their encrypted data

### [FamilyFinances](https://github.com/carlos-aisa/FamilyFinances)

Ledger-first personal finance platform implemented as a modular .NET application.

* Explicit accounting rules and balanced transaction splits
* ASP.NET Core API and Blazor web interface
* EF Core, Identity, JWT and SQLite
* Unit, integration and component testing
* Reporting, backup and restore workflows
* Automated CI, security analysis and Windows distribution

### [OutreachFlow](https://github.com/carlos-aisa/OutreachFlow)

Lightweight CRM and controlled email outreach manager for small organizations and independent professionals.

* Contact, organization and audience management
* Reusable templates and personalized draft generation
* Human approval before sending
* Provider abstraction and complete communication history
* Safety rules for consent, duplicate sends and unresolved variables
* ASP.NET Core, Blazor, EF Core and automated testing

* Keep business rules independent from infrastructure.
* Prefer useful tests over superficial coverage.
* Treat security and observability as design concerns.
* Automate builds and releases, but keep the process understandable.
* Use AI to accelerate engineering without delegating technical judgment.
